# Google Landing Page Clone 🌐

Un clon de la página de inicio de Google desarrollado desde cero como ejercicio de práctica para fortalecer mis habilidades en maquetación web. Este proyecto se centra en la implementación de interfaces limpias, semánticas y adaptables, utilizando técnicas modernas de CSS.

---

## 🚀 Tecnologías Utilizadas

- **HTML5**: Estructura semántica orientada a la accesibilidad.
- **CSS3**: Implementación de Flexbox, variables globales para control de diseño y diseño responsivo.
- **SVG**: Integración de iconos vectoriales optimizados para un rendimiento superior.

## 💡 ¿Qué hace especial a este proyecto?

Este proyecto fue un desafío técnico para:

* **Abstracción de Diseño**: Uso de **variables CSS (`:root`)** para centralizar la paleta de colores y transiciones, permitiendo cambios rápidos y escalables en todo el sitio.
* **Optimización Semántica**: Estructuración del DOM sin el uso innecesario de `divs`, manteniendo un código fuente ligero y limpio.
* **Accesibilidad y UX**: Implementación de estados `:hover` y `:focus` pensados para mejorar la navegación tanto por mouse como por teclado.
* **Integración de Recursos**: Gestión eficiente de assets mediante URLs externas, optimizando el rendimiento y la mantenibilidad.

## 🛠️ Desafíos Superados

- **Posicionamiento con Flexbox**: Dominio de la alineación de elementos en cabeceras y pies de página.
- **Estilización de Inputs**: Creación de un buscador interactivo con icono integrado, utilizando posicionamiento absoluto y `pointer-events` para una experiencia de usuario fluida.
- **Código Robusto**: Limpieza profunda del código CSS, eliminando redundancias y aplicando la metodología DRY (*Don't Repeat Yourself*).
